# AI Document Chatbot (RAG)

An AI-powered chatbot that allows users to upload PDF documents and ask questions using Retrieval-Augmented Generation (RAG).

## Features
- Upload PDF documents
- Extract and process text
- Semantic search using vector embeddings
- AI-generated answers using OpenAI

## Tech Stack
- Python
- Streamlit
- LangChain
- OpenAI
- FAISS

## How it Works
1. Upload PDF
2. Text is split into chunks
3. Embeddings are created
4. Relevant chunks are retrieved
5. AI generates answer based on context
